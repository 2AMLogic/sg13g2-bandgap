- **Experiment**: closed-loop-startup
- **Claim**: co-simulating bandgap_core + bandgap_amp + bandgap_startup
  in one netlist (design/bandgap_top.sch's own wiring: core.fb <-
  amp.out, core.sns1 -> amp.in_n, core.sns2 -> amp.in_p, startup
  shares sns1 and fb with the core), with vdd itself ramped 0 -> VDD
  over 200 us, the assembled block self-starts and settles to a
  closed-loop operating point across the full temperature x supply x
  HBT/MOS/resistor-process-corner PVT grid: the startup circuit fully
  releases (v(det) <= 0.2*vdd, |i(XMKFB)| <=
  50e-9 A), the real error amplifier closes the loop
  (|sns1-sns2| <= 0.020 V), and fb settles to a real
  interior equilibrium rather than railing to either supply (fb
  within [0.05 V, vdd-0.05 V]). This is
  the first genuinely closed-loop testbench in this tree -- every
  prior PVT-sweep testbench (sim/core-open-loop-bias,
  sim/startup-core-handover, and their -pex variants) substituted an
  ideal diode-connected-replica current fixture for the not-yet-built
  amplifier (design/README.md, issue #9's scope cut). No ratified
  spec row exists yet (#13); this record is closed-loop
  infrastructure/plumbing evidence -- the assembled block starts and
  settles -- not a claim against any spec accuracy/PSRR/Iq target.
