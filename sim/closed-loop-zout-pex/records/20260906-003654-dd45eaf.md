# Record 20260906-003654-dd45eaf

- **Experiment**: closed-loop-zout-pex (issue #191 -- independent
  confirmation of sim/closed-loop-psrr-pex's 27.1-31.6 MHz
  worst-case-PSRR dip)
- **Claim**: through the SAME co-simulated closed-loop topology
  sim/closed-loop-psrr-pex uses (bandgap_core + bandgap_amp +
  bandgap_startup, wired exactly as design/bandgap_top.sch
  specifies, loop NOT broken, same layout-extracted device/
  parasitic block), a small-signal AC closed-loop OUTPUT-IMPEDANCE
  curve is measured by injecting a 1A/0deg AC test current directly
  at vref (vdd left as a plain, unperturbed DC source -- NOT the
  stimulus in this bench) around a DC operating point seeded via
  .nodeset from sim/closed-loop-startup's own most recent per-corner
  converged transient endpoint and re-verified per point
  (|fb_op - fb_seed| <= 0.05 V). Zout(f) = v(vref)/
  i(Itest), numerically equal to v(vref) in ohms since Itest's AC
  magnitude is exactly 1A. This is a DIFFERENT transfer function
  than PSRR (different stimulus port entirely) that shares the same
  1/(1+T(jw)) return-difference denominator -- see README.md 'Why an
  output-impedance probe' for why a peak here at the same frequency
  as sim/closed-loop-psrr-pex's own dip is evidence for a genuine
  loop resonance rather than a vdd-injection-path artifact.
- **Devices**: XM1/XM2A/XM2B/XM3A/XM3B/XM3C/XR1/XR2 (bandgap_core),
  XMTAIL/XMP1-4/XMN1-4 (bandgap_amp), XRPU/XMSENSE/XMKFB
  (bandgap_startup) -- all 17 MOS + 3 resistor devices extracted
  from `layout/bandgap_top/bandgap_top.pex.spice` (layout git sha
  `8abe2aa`), instance-for-instance matching
  design/netlist/bandgap_core.spice, bandgap_amp.spice and
  bandgap_startup.spice (same models, same nominal w/l/ng/m -- the
  extraction only adds as/ad/ps/pd). XQ1/XQ2/XQ3 (npn13G2) are NOT

  devices -- spliced verbatim from
  `design/netlist/bandgap_core.spice` (schematic git sha

  benches use (same choice, same rationale, as
